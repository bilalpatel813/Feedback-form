# Feedback Form

A simple web-based feedback form built using Flask, MySQL, and basic HTML/CSS. It allows users to submit feedback which is stored in a database.

# Features

- Clean and simple UI
- Submit feedback easily
- Store data in MySQL
- Lightweight Flask backend

# Tech Stack

- HTML, CSS
- Flask (Python)
- MySQL

# Setup

1. Clone the repo

git clone https://github.com/bilalpatel813/Feedback-form.git
cd Feedback-form

2. Install dependencies

pip install flask mysql-connector-python

3. Setup database

- Create a MySQL database
- Import "database.sql"
- Update credentials in "app.py"

4. Run the app

python app.py

5. Open in browser

http://127.0.0.1:5000/

# Usage

Fill the form and submit. Data will be stored in the database.
